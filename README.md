# NightDesk

A self-hosted start page with customizable links, backgrounds, and multi-provider search. Packaged as personal and blank team versions for simple internal deployment and sharing.

## Features

- 🎨 Customizable links and backgrounds
- 🔍 Multi-provider search (Google, Bing, DuckDuckGo, etc.)
- 👥 Blank team template for easy internal deployment
- 📦 Export/Import configuration as JSON
- 🌐 No build step required - just open index.html

## Quick Start

### Option 1: Open Directly
Just open `index.html` in your browser - it's a fully self-contained static page.

### Option 2: GitHub Pages (Hosted)
If GitHub Pages is enabled, access via: `https://damienywh.github.io/Nightdesk/`

### Option 3: Self-Hosted
Upload the files to any web server or NAS. Works great on local networks for team start pages.

## Configuration

1. Click **Settings** to add or edit search providers
2. Click **Edit mode** to add groups and links
3. Use **Import** to bring in a NightTab backup JSON
4. Use **Export** to save a self-hosted config JSON for re-use

Your changes are stored in the browser's local storage. Export your config to keep a backup!
