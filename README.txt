NightTab-style blank template

This package starts with no personal links.

How to use
1. Open index.html directly, or host the folder on an internal web server.
2. Click Settings to add or edit search providers.
3. Click Edit mode to add groups and links.
4. Use Import if you want to bring in a NightTab backup JSON.
5. Use Export to save a selfhosted config JSON for re-use.
