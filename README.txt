NightTab local-drive package

Open index.html directly from your local drive.

This build saves settings in the browser using IndexedDB, so settings like tile width, height, icon size, providers, and edits persist from file:///.

Import:
- NightTab backup JSON
- selfhosted export JSON

Export:
- selfhosted JSON
- NightTab-style JSON

Reset local saved version:
- Settings > Reset local saved version
